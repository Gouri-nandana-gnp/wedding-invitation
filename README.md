# Wedding Invitation — Sandeep & Ardra

A mobile-first luxury wedding e-invite inspired by modern cinematic invitation designs.

## Flow

1. **Intro** — Arched couple photo, names, date, “Open Invitation” button
2. **Invitation** — Scrollable sections:
   - Welcome message with florals
   - Groom & Bride (with parents)
   - Wedding event details + View Map
   - Gallery (circular photos, swipe)
   - Thank you + social share

## Floating actions

- **Music** — bottom-left lavender button
- **Map** — bottom-right location button

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/lib/constants.ts` for names, dates, venue, parents, and gallery images.

Replace `public/images/couple-intro.png` with your couple photo.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
